# Photos

The site ships with original illustrated scenes (`*.svg`). To use real photographs, drop JPGs
into this folder with these exact names — they automatically replace the illustration, no code changes:

| File                     | Used on                         | Suggested size |
|--------------------------|---------------------------------|----------------|
| `hero.jpg`               | Homepage hero (dark overlay applied) | 1920×1080 |
| `service-laundry.jpg`    | Home service card + Services banner | 1200×800 / 2100×700 |
| `service-cleaning.jpg`   | Home service card + Services banner | 1200×800 / 2100×700 |
| `service-painting.jpg`   | Home service card + Services banner | 1200×800 / 2100×700 |

Use only photos you own or are licensed to use (ideally your own work). Keep each under ~300 KB.
